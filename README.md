# 📝 To-Do App

A simple and responsive To-Do App built with React and Supabase. It allows users to create an account, log in, and manage their tasks easily.

## ✨ Features

- 🔐 User Sign Up & Login
- 👤 Name, Email & Password Authentication
- ➕ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📱 Fully responsive design
- ☁️ Tasks stored using Supabase

## 🛠️ Built With

- React
- JavaScript
- CSS
- Supabase
- Vite
